# Iorrany: fluxo na pele

CONFIRMED: redesign para Iorrany, especialidade suminagashi, foco nos trabalhos enviados. Conversão WhatsApp 5561993941961, Instagram ioiotattoo, TikTok ioio.tattoo, localização One Park Mall conforme link do cliente. Remover conteúdo, fotos e ornamentos da identidade anterior. Mobile first. Pasta independente, sem vínculo com o deploy anterior.

Marca PARTIAL. Gate PASS para implementação. Público inferido: pessoas interessadas em tatuagem autoral abstrata; nenhum recorte demográfico inventado. Sem alegar anos de carreira porque o post não tem data confirmada. Sem inventar depoimentos ou detalhes de sessões. Estudos desenhados separados de tatuagens executadas.

Direção: brutalismo compacto com Barlow Condensed Bold (OFL), DM Sans local para leitura. Base #090a0d, prata #e9e9e5, azul #8bb6ff, vermelho #ed6478, roxo #be9dff. Fotos mantêm suas cores reais. Fundo procedural cromado varia lentamente com tempo e scroll. Texto protegido por superfícies estáveis. Trilhos laterais mantidos. Sem emojis, crisântemos ou dragão decorativo.

Referências consultadas: Codrops Liquid Distortion (deformação contínua), Shaders on Scroll (mudança gradual), Godly TRUE (tipo e imagem). Biblioteca aprovada triada: catálogos React Magic/Cult/21st não necessários para HTML nativo; Haikei não adequado para suminagashi; Blender/Three não necessários para shader 2D; GSAP/Motion não necessários para RAF e transições simples. Skills: free-design-resource-router, reference-first-design, ui-skills-root, frontend-design. ROLE_MAP ausente no caminho indicado.

Playlist Spotify confirmada via embed público: Play na tattoo, iorrany.araujo. Moby, alt-J, Woodkid, Gorillaz, Linkin Park, BaianaSystem entre os artistas. Inspiração de contraste e cadência, não sincronização de áudio. Embed só carregado por clique, sem autoplay.

Limitações: recorte de logo 102x134, fotos com resoluções variadas e alguns controles de captura. Usar logo pequeno; não ampliar imagens pequenas como hero. Instagram/TikTok não acessíveis via leitura pública nesta sessão. Browser integrado indisponível (bridge sem confiança); QA alternativo com Chromium local.

WebGL: um canvas, 30fps, até 1 milhão de pixels, DPR 1.25, queda adaptativa de resolução, parada em aba oculta/modal, fallback estático para movimento reduzido, economia de dados e falha de contexto. Não é simulação física de tinta ou metal; interpretação gráfica original.
